# Tab Volume Dial

A free Chrome extension by [Aimplify Solutions LLC](https://aimplifysolutions.com/) for controlling the volume and sound of individual tabs.

- Volume from 0% to 1000%, with live meters and peak protection
- Five-band EQ, Speech, Night and Music modes, audio leveling, and stereo balance
- Site and global presets, themes, and accent colors

To try the source locally, open Chrome's Extensions page, enable Developer mode, and choose **Load unpacked**. Select the folder containing `manifest.json`.
